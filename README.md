# Openjacks

확률과 통계 학습용으로 만든 블랙잭 시뮬레이터입니다.  
실제 플레이 흐름을 유지하면서 카드 분포, 카운트, 기본 전략, 세션 통계를 함께 보도록 구성했습니다.

## 주요 기능

- 블랙잭 기본 진행
- 히트, 스탠드, 더블, 스플릿 지원
- 칩 기반 베팅 UI
- 시작 자금 `$25`
- 베팅 칩 단위: `$1`, `$5`, `$10`, `$25`, `$50`
- 올인 베팅 지원
- 테이블 위 베팅 칩 추가 및 개별 회수
- 기본 전략 추천 및 라운드별 의사결정 정확도 기록
- 세션 종료 통계 및 라운드별 복기
- 하이카드/로우카드 비율, 러닝 카운트, 트루 카운트 표시
- 가로/세로 화면에 맞춘 반응형 레이아웃

## 단축키

- `1`: `$1` 칩 추가
- `2`: `$5` 칩 추가
- `3`: `$10` 칩 추가
- `4`: `$25` 칩 추가
- `5`: `$50` 칩 추가
- `Q`: 히트
- `W`: 스탠드
- `E`: 더블
- `R`: 스플릿
- `T`: 올인
- `F`: 라운드 시작 또는 다음 라운드 진행
- `Esc`: 올린 베팅 칩 전부 회수

통계, 기록, 설정 오버레이가 열려 있을 때는 단축키가 비활성화됩니다.

## 실행

필수:

- Node.js

설치:

```powershell
npm install
```

개발 서버:

```powershell
npm run dev
```

타입 체크:

```powershell
npm run lint
```

빌드:

```powershell
npm run build
```

## 통계 학습 포인트

- 세션 전체 승/패/무승부 집계
- 총 베팅량, 평균 베팅, ROI
- 평균 손익, 중앙값, 사분위수, 표준편차
- 평균 손익의 95% 신뢰구간
- 플러스 수익 비율
- 최대 낙폭, 최대 낙폭률
- 최장 연속 수익/손실
- 각 라운드별 실제 선택과 기본 전략 비교

## 배포

GitHub Pages 배포는 `.github/workflows/deploy.yml` 기준으로 동작합니다.

커스텀 도메인:

- `openjacks.mcv.kr`

관련 파일:

- `public/CNAME`
- `.github/workflows/deploy.yml`

## 규칙 메모

- 블랙잭 배당 `3:2`
- 딜러는 모든 `17`에서 스탠드
- 보유 칩이 `0`이 되면 세션 종료 결과를 확인 가능
